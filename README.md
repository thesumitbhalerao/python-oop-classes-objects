# Python OOP Homework – Classes and Objects

## Project Information

- **Subject:** Python Programming
- **Topic:** Object-Oriented Programming (OOP)

## About This Homework

This repository contains my Python homework based on Object-Oriented Programming (OOP). The purpose of this assignment is to understand how classes, constructors, objects, and attributes work in Python.

## Concepts Covered

- **Class:** A blueprint used to create objects.
- **Constructor (`__init__`):** Initializes an object's attributes when it is created.
- **Object:** An instance of a class.
- **Attributes:** Store information about an object.
- **`self`:** Refers to the current object.

## Classes Included

1. **PMPML** – Stores bus numbers and routes.
2. **Mess** – Stores mess names and food types.
3. **TeaHouse** – Stores shop names and prices.
4. **PG** – Stores PG names and rent details.
5. **Perfume** – Stores perfume brands and prices.
